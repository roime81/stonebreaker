## How to get actual runtime logs

For Compose services, run `docker compose logs --follow backend` or `docker compose logs --follow postgres` from the repository root. For a one-time view, use `docker compose logs --tail=100 backend`. A locally launched Uvicorn process writes its output to that process's terminal. Runtime logs are generated by the running services; they are not represented by entries in this curated file. Review output before sharing it and redact credentials, DSNs, API keys, customer data, and other sensitive values.
